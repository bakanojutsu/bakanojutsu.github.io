Privacy Policy

Last updated: October 2026

This Privacy Policy applies to the Gmail Automation Tool ("the Application"), a private Google Cloud API integration tool created for internal and personal use.

1. Scope of Application

The Application is strictly designed for personal script automation executed locally on developer-controlled hardware. It is restricted to the developer and up to two designated test user accounts owned by the developer.

2. Data Collection and Usage

The Application requests permission to access Gmail APIs solely to execute personal, user-defined scripts. Specifically:

  • No External Storage: The Application does not transmit, upload, or store any email contents, user credentials, or personal metadata to external servers or third-party databases.
  • Local Processing: All data processed through the Gmail API remains strictly within the local environment where the script is executed.
  • No Analytics: No tracking, telemetry, or analytics data is collected from the user or device.

3. Use of Google User Data

The Application's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. Data Sharing and Disclosure

We do not sell, trade, rent, or transfer your Google user data or personal data to any third party under any circumstances.

5. Data Security

OAuth 2.0 authentication tokens used by the application are stored locally and securely on the developer's authorized device. Tokens can be revoked at any time via the user's Google Account security settings.

6. Contact Information

For any questions regarding this Privacy Policy or the application, please open an issue in the associated GitHub repository: github.com/bakanojutsu.
