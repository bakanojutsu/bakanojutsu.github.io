Gmail Automation Tool

This is a private Google Cloud Application created solely for personal scripting and personal email automation tasks.

Project Overview

  • Purpose: Used for programmatic access to manage and automate personal Gmail workflows via custom scripts.
  • Scope: Personal use only. The application operates strictly on local developer environments.
  • Access Control: Access is restricted exclusively to the account owner and up to two explicitly designated test clients owned by the developer.

Data Handling Notice

This application does not collect, store, transmit, or share any user data with third-party servers. All operations execute locally on the authorized hardware.
